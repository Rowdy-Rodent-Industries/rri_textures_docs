
# How to work with Github

## Downloading Git
- Use the link provided in the Orientation or [Git Download](https://git-scm.com/) to download git
- Follow all steps of the install, with default options for each

## Downloading Git LFS
- Use the link provided in the Orientation or [Git LFS Download](https://git-lfs.com/) to download git LFS
- Install the extension and follow all default prompts
- From there, open a command prompt or "cmd" application and run "git lfs install". 
- That's it! Your git is se tup

## Clone Texture drive
- To first download the texture drive you need to "Clone it" onto your computer, to do that you're going to copy the link to the github here 
    - https://github.com/Rowdy-Rodent-Industries/rri_textures.git

- Go to a blank place where you want to store this repository of textures, preferably one with some space as it's gonna take some space on your computer 
- Click anywhere on the file explorer and click "Open GitBash Here"
    - If your on windows 11 you'll need to click "see more options" before you see it
- In the git bash you will type the following 
    - Git Clone https://github.com/Rowdy-Rodent-Industries/rri_textures.git
    - Crtl + V Doesn't work on the bash so you'll need to paste it manually or Shift + Insert works too
- From there you've cloned the drive!
