### THE TEXTURE PIPELINE

**01 · Review** → **02 · Claim** → **03 · Create** → **04 · Test** → **05 · Submit**

1. Read the [texture rules](texture-rules) and [file naming standards](texture-name-system).
2. Claim an approved request using the [claiming guide](how-to-claim).
3. Follow the [2D](how-to-2d-texture) or [3D](how-to-3d-texture) workflow.
4. [Test the texture in Arma 3](uploading-textures-into-arma).
5. Submit the source files for approval following the [submission process](how-to-claim).
