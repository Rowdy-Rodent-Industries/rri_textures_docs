# Texture File Naming System


Use the following exact naming patterns for texture files. Replace `[Name]` with the appropriate name while preserving capitalization, underscores, and suffixes.

## Trooper Helmets

| Component | Filename pattern |
| --- | --- |
| P1 Helmet | `Phase1_Helmet_[Name]_co` |
| P1 SpecOps | `SpecOpsHelmet_[Name]_co` |
| P2 Helmet | `Clone_helmet_P2_[Name]_co` |
| ARF Helmet | `Helmet_ARF_[Name]_co` |
| AB Helmet | `Clone_helmet_AB_[Name]_co` |
| Engineer Helmet | `Helmet_engineer_[Name]_co` |
